# 财经共情单幅漫画

## 目标与边界

本模式用一张原创人物漫画和一段短配文，把普通人的金融处境转化为“先被看见，再多懂一步”的阅读体验。它适合工资、账单、房贷、消费、储蓄、保险、投资波动、养老、税费、通胀和职场收入等主题。

共情不等于煽情。不得将贫穷、债务、年龄、疾病或投资亏损画成笑料，不用恐惧、羞耻或优越感逼迫读者认同。不得复制参考图的具体人物、比例、笔触、文字、印章、签名、构图或固定笑点，只提炼“单一隐喻、朴素人物、短自白、认知反转”的一般方法。

## 默认全流程

用户选择本模式且平台已明确后，不再停留在选题、稿件或分镜阶段，默认完成到最终图片：

1. 联网扫描近期投资和财经热点、读者高频困惑及流行情绪表达。
2. 建立候选题池并选出一个最适合视觉化、最容易产生共情且事实可核验的主题。
3. 完成事实底稿、标题、系列结构、原创笑点与逐张配文。
4. 在内部完成共情卡片预演表并校正误导风险，不等待额外确认。
5. 生成无关键文字的原创插画底图，后期确定性添加中文、数字、页码和品牌。
6. 检查事实、笑点原创性、移动端阅读、视觉连贯、标点和 Logo 后交付最终图片及来源。

用户明确要求“先看稿”“只要文案”或“只出一张测试图”时，按其范围交付，不强制跑完整流程。

## 联网热点与笑话研究

每次执行都以当前日期重新搜索，不复用过期热点清单。默认先看最近 24–72 小时，再扩展到最近 7 天；若主题需要更长背景，再补最近 30 天和长期数据。搜索应同时覆盖：

- **事实层**：监管机构、央行、统计机构、交易所、政府部门、上市公司公告、基金定期报告等一手来源。
- **解释层**：可靠财经媒体与专业机构对事件机制的解释。机构观点必须标为观点，不能写成确定事实。
- **情绪层**：投资者社区、评论区、问答、搜索趋势和流行段子，用于发现读者怎么说、在怕什么、误解什么。情绪层内容不能单独支持数字、政策、行情或投资结论。

每个候选热点至少记录事件日期、事实来源、普通读者影响、典型情绪、可视化隐喻和误导风险。优先选择同时满足以下条件的题目：

- 与普通人的钱直接有关，而非只对专业交易者有意义；
- 近期确有讨论热度，但不是只有一个来源在炒作；
- 能用一个清楚的生活动作表现，不依赖复杂行情图；
- 有稳定的金融机制可解释，热点退去后仍有认知价值；
- 不需要预测涨跌、推荐个股或鼓动交易才能成立。

遇到“谐音概念股”“神秘代码”“内幕消息”“老师带单”“稳赚策略”等内容，只能作为非理性行为、骗局或情绪传播的科普对象，不能顺着热度包装成交易机会。

### 网络笑话的原创转译

网络笑话和投资梗只作为观察材料。不要复制完整原句、固定包袱、表情包人物或热门画面。先抽取其结构，再围绕本次事实重新创作：

1. 原期待是什么；
2. 哪个财经变量让期待落空；
3. 普通人会做出什么可见动作；
4. 最后一句怎样既好笑又更准确。

例如可提炼“嘴上长期投资，手上每分钟刷新”“收益还没到账，费用先扣完”等矛盾结构，但最终配文和画面必须根据本次热点重新写。笑点不能建立在具体个人的损失、疾病、年龄、职业、地域或消费能力之上。

## 选题与吸引力判断

没有用户指定主题时，对候选题按以下顺序判断：读者相关性、情绪共鸣、事实可信度、视觉反差、时效性和长期认知价值。热度高但无法核验、只能靠夸张标题、或容易被读成投资建议的题目直接淘汰。

成稿至少形成一条完整阅读路径：

`热点钩子 → “这就是我”的处境 → 背后机制 → 常见误解或风险 → 一个可观察的数字/问题 → 有余味的收尾`

卡片数量由内容决定，不为凑张数重复笑点。第一张必须在三秒内交代“最近发生了什么”或“我的钱为什么有感觉”；第二张尽快让读者认出自己的生活动作；中段用最少页面讲清机制；结尾不给买卖指令，而是留下一个可执行的观察问题。

吸引力来自具体矛盾和视觉反差，不来自标题党。封面或首张可以用疑问、反常动作或熟悉痛点，但不得省略会改变含义的对象、日期、期限或条件。

## 一张图的四层结构

1. **真实时刻**：先落到一个读者经历过的动作，例如工资到账、信用卡还款、续保、看净值、买菜、收到房贷扣款或给父母转账。
2. **表层情绪**：写清当下感受，例如松一口气、心虚、麻木、犹豫、庆幸或被数字吓到。不要泛写“成年人好难”。
3. **财经机制**：找出感受背后的真实变量，例如固定支出、现金流错配、复利、购买力、机会成本、风险承受能力或保障缺口。
4. **认知落点**：最后给读者一个轻微转向，不要求解决人生，只让他看见“原来卡住我的不是意志力，而是现金流结构”之类更准确的解释。

每张至少让第 1、3 层在画面中可见，第 2、4 层在配文中完成。若只有情绪而没有财经机制，改写；若只有术语而没有真实时刻，改写。

## 视觉隐喻方法

- 将抽象财经关系变成一个可见动作：工资被固定支出排队分走、购买力被物价一点点擦薄、复利像缓慢滚大的雪球、流动性像抽屉里够不到的现金。
- 优先使用“一人＋一物＋一个反常变化”。人物承担情绪，物件承担财经概念，反常变化制造记忆点。
- 隐喻必须可反译。读者看到“漏水的钱包”时，应能明确对应持续小额支出；若能解释成许多无关主题，说明隐喻太泛。
- 夸张只放大关系，不篡改机制。不能把短期波动画成必然归零，不能把保险画成稳赚，不能把借贷画成无成本救命钱。
- 画面上半部优先承担主体动作，下半部留给配文；人物不必写实，但姿态和表情必须一眼可读。每张只保留支持核心隐喻的道具。

## 共情配文写法

配文像读者脑中的一句话，不像老师点评读者。推荐 18–50 个汉字、2–4 行，口语自然，结尾有轻微停顿或转向。文字不必解释完整机制，但必须准确指向画面中的财经锚点。

优先使用以下结构，按内容选择，不机械套模板：

- **具体瞬间＋真实反应**：“工资到账那一刻，我先高兴了三秒，然后开始给账单排队。”
- **别人以为＋我的处境**：“别人说我不爱花钱，我只是每个月都先替未来交作业。”
- **我以为＋其实**：“我以为自己缺的是自制力，后来发现，先缺的是一笔能喘气的现金流。”
- **不是 A＋而是 B**：“我不是不敢投资，是这笔钱三个月后就要交房租。”
- **物件拟人＋财经真相**：“购物车最懂我，每次降价都劝我多花一点。”
- **轻微自嘲＋准确落点**：“我的收益率还在努力，我的手续费已经提前下班了。”

配文的共情检查：

- 是否有读者能想起的具体时刻，而不是抽象人生感慨？
- 是否站在读者身边，而不是替读者诊断、说教或贴标签？
- 反转是否带来更准确的财经理解，而不只是抖机灵？
- 删掉插画后，配文是否仍能指向一个明确财经主题？删掉配文后，画面是否仍能看出同一处境？
- 是否避免“穷是因为不努力”“亏钱是因为笨”“买不起就是不配”等羞辱性因果？

## 财经选题转译

- 收入：到账金额与可支配金额之间的落差；奖金的不确定性；工资增长与物价变化。
- 支出：固定支出先分走收入；小额订阅的累积；折扣诱发的额外消费；机会成本。
- 储蓄：应急资金带来的选择权；流动性与收益的取舍；目标储蓄的时间感。
- 借贷：月供对现金流的约束；名义利率之外的总成本；提前消费与未来收入的交换。
- 投资：波动带来的情绪；持有期限与用钱时间不匹配；收益率、费用和风险承担的关系。
- 保险：买的是风险转移而非返本幻觉；保额、免赔额和责任范围；家庭责任与保障缺口。
- 宏观：物价变化如何进入日常账单；利率如何影响月供、存款与估值；汇率如何影响留学、旅行和进口商品。
- 养老与税费：今天的现金流与未来保障如何交换；政策条件、身份与口径如何改变结果。

## 系列编排

系列通常选择一个财经母题并从浅到深展开。可采用“感觉到了 → 为什么会这样 → 哪个数字值得看 → 常见误解 → 更稳妥的判断”顺序。每张独立成立，不要求连续剧情，但下一张应回答上一张留下的更深问题。

同一系列保持：原创角色基本轮廓、黑线粗细、低饱和点色、配文区域、财经对象的颜色语义和品牌位置。角色可以更换年龄与职业，但不能用外貌刻板印象代表收入、信用或风险偏好。

## 内部预演表

每张先写：

| 项目 | 内容 |
|---|---|
| 目标读者 | 谁最可能经历这个时刻 |
| 具体财经时刻 | 一个可观察动作 |
| 表层情绪 | 读者当下感受 |
| 背后机制 | 准确的财经解释 |
| 视觉隐喻 | 一人＋一物＋反常变化 |
| 配文 | 18–50 字，2–4 行 |
| 多懂一步 | 看完新增的判断 |
| 风险边界 | 不能被误解成什么 |

预演表完成并通过事实、共情和误导风险检查后直接生成图像，不默认停下来等待用户确认。只有用户明确要求先审稿时才展示并等待确认。配文、数字、标点和品牌名称均后期确定性排版，不交给图像模型绘制。

## 交付检查

- 三秒内能否识别人物情绪和核心财经对象？
- 画面是否只有一个主要隐喻，并能准确反译回财经概念？
- 配文是否像普通人的心声，同时提供了认知转向？
- 是否包含真实财经锚点，而不是换个标题就能用于任何情绪主题？
- 是否没有复制参考图的角色、手写字、落款、印章或具体创意？
- 涉及数字、政策或行情时，是否写清日期、对象、口径和必要条件？
- 是否使用原始 Logo 和“森财有方”完成唯一一次确定性署名？
- 热点是否来自本次联网检索并标明截至日期？事实是否有权威来源，社交讨论是否只用于情绪观察？
- 笑点是否经过原创重构，既能吸引读者，又没有复制网络原句或暗示具体交易机会？
- 是否已完成最终插画、排字和品牌叠加，而不是只交付选题、文案、分镜或提示词？
