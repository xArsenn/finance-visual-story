# 历史人物财经客串库

## 用途

仅在财经漫画需要解释概念来源、思想演变、数学工具或历史场景时读取。阿森与米露是现行长期视觉主角；阿杰保留核验功能，视觉形象尚未确定。本库人物只承担单个知识点的短暂客串。

## 选择门槛

历史人物必须同时满足：

1. 已故且主要身份不是政治人物、军事领袖或宗教领袖。
2. 没有足以压过科普主题的重大公共争议。
3. 与当前知识点存在可核验的直接联系，而不是为了“名人感”硬塞。
4. 能用原创概括形象表现，不依赖受保护的影视造型、名画构图、品牌资产或著名照片。
5. 其出场能增加理解；删掉后若知识完全不受影响，优先不使用。

无法确认人物是否合适时，使用匿名历史职业角色，例如早期账房、交易所经纪人、航运商人、银行柜员或债券持有人。

## 中国历史人物首批候选

| 人物 | 适合主题 | 可承担的漫画动作 | 表达边界 |
|---|---|---|---|
| 司马迁 | 商业史、产业分工、区域物产与流通 | 翻开《史记·货殖列传》，把农业、手工业、商业和物产放到同一张流通地图上 | 只说明其记录和观察，不把经验性总结包装成现代经济学模型；不使用影视化太史令造型 |
| 刘徽 | 数量核验、比例、误差、计算方法 | 用算筹逐步验算一组成本、面积或分配问题，让阿杰检查计算过程 | 主要身份是数学家；不能把现代财务公式倒推成他的发明，也不照搬后世想象画像 |
| 贾思勰 | 农业经营、季节性生产、储存、投入产出 | 对照节气、土地、种子和储藏条件，演示经营结果为何随条件改变 | 《齐民要术》是农学著作；只能借其生产经验解释经营条件，不能写成现代企业管理或投资理论 |
| 宋应星 | 生产流程、原料、工艺、供应链与效率 | 沿一件产品拆开原料、加工、运输和成品环节 | 以《天工开物》记载的生产技术为依据；不把历史工艺直接等同于现代工业供应链，也不临摹书中版画 |
| 程大位 | 珠算、商业计算、成本、折算和账目核对 | 用算盘计算货物数量、价格、折算与结余，再让米露换成现代计算式 | 可称明代珠算家及应用数学著作者；不夸张成会计制度或金融理论的发明者 |
| 杨辉 | 组合、数表、逐层计算 | 用数字表展示多步计算和组合关系 | 只用于数学工具或概率直觉；不把“杨辉三角”直接说成投资预测工具 |
| 朱世杰 | 多元问题、未知数、系统求解 | 把多个未知条件摆成算筹阵列，逐项求解 | 只解释多变量计算直觉，不声称其建立了现代金融模型 |

以上人物的时代服装、冠帽、胡须、算筹、算盘和书案只作为通用历史线索。不得依照某一幅古画、教科书标准像、纪念雕塑、影视剧照或博物馆复原图逐项复制；面部必须重新设计成与 Style005 一致的原创漫画概括形象。

## 其他地区首批低风险候选

| 人物 | 适合主题 | 可承担的漫画动作 | 表达边界 |
|---|---|---|---|
| 亚当·斯密 | 分工、市场交换、价格协调 | 在别针工坊拆分工序，观察交换 | “看不见的手”不能被画成市场万能论；需同时说明制度与信息条件 |
| 约翰·梅纳德·凯恩斯 | 总需求、流动性偏好、经济波动 | 面对闲置产能和就业账本解释需求不足 | 不把复杂理论缩成“政府花钱就能解决一切” |
| 阿尔弗雷德·马歇尔 | 供给、需求、均衡价格 | 用剪刀两刃或两条曲线展示共同决定价格 | 不暗示价格永远自动、立即回到均衡 |
| 威廉·斯坦利·杰文斯 | 边际效用、边际决策 | 比较第一杯水与第五杯水的主观价值 | 不把边际效用直接等同于市场价格的全部来源 |
| 卡尔·门格尔 | 主观价值、边际效用 | 让不同人物对同一物品给出不同价值判断 | 不把学派立场包装成唯一结论 |
| 卢卡·帕乔利 | 复式记账、借贷平衡 | 在账簿两侧记录同一笔交易 | 说明其是系统整理和传播的重要人物，避免绝对化成“唯一发明者” |
| 斐波那契（比萨的莱昂纳多） | 数列、复利直觉、增长节奏 | 用连续月份或兔子数量演示递推 | 不传播“斐波那契数列精确预测市场”的伪科学，也不滥用黄金分割神话 |
| 丹尼尔·伯努利 | 风险、期望效用、财富边际效用 | 比较同一笔钱对不同财富水平人物的意义 | 不把理论写成适用于所有人的精确心理定律 |
| 路易·巴舍利耶 | 随机价格运动、概率与金融 | 在黑板上展示价格路径可能向上或向下 | 不写成“市场价格完全随机”或“技术分析全部无效”的绝对结论 |
| 托马斯·格雷欣 | 货币流通、“劣币驱逐良币”的条件 | 两种法定等值但实际价值不同的硬币进入市场 | 必须写明法定比价和流通条件；该规律的命名与思想来源可有历史讨论，不讲成无条件定律 |
| 艾萨克·牛顿 | 复利计算、市场泡沫中的认知偏差 | 一边计算，一边面对无法由公式消除的市场情绪 | 涉及南海泡沫轶事或名言时必须另行核验来源，不把网传金句当原话 |
| 阿基米德 | 杠杆的直觉、放大效应 | 用长短不同的杠杆抬起同一重量 | 只用于解释“放大”的物理直觉；金融杠杆还会同时放大亏损，必须紧邻说明 |

## 默认禁用类别

- 历任或现任国家元首、政府首脑、政党领袖、重要政治活动家及高度政治化人物。
- 军事领袖、殖民统治核心人物、极端主义人物、战争罪或严重人权争议人物。
- 宗教创始人、宗教领袖和可能被理解为宗教评价的具名人物。
- 犯罪人物、金融诈骗者、操纵市场者，以及主要因争议、丑闻或暴力事件知名的人物。
- 在世公众人物、近期去世且仍具有强商业肖像价值的人物、财经网红、企业家明星和投资偶像。
- 与当前知识点无直接关系，只因知名度高而被放入画面的名人。

## 出场方式

- 每位历史人物默认只占一个阅读拍，必要时最多连续两个阅读拍。
- 第一次出现时用小标签写清“姓名＋与本页有关的身份”，不堆出生卒年和完整生平。
- 优先安排其做一个能解释机制的动作；对白只保留一句认知触发或漫画化演绎，其余事实由阿森或阿杰核验。
- 阿森负责把历史场景翻译回现代财经概念，米露负责提出“这和现在有什么关系”，阿杰负责补来源、条件或争议边界。
- 历史人物离场前必须完成“回到今天”的桥接，不能让读者停留在历史趣闻。

## 事实与肖像检查

- 查证姓名译法、时代、主要贡献及本页使用的具体事实；存在学术争议时明确使用“常被归纳为”“后来以其名字命名”等克制表述。
- 不杜撰具体日期、收益、损失金额、发明归属或原话。
- 造型使用同篇统一的原创手绘语言，只保留时代服装、发型或工具等非专属识别线索。
- 不依据单一受保护肖像逐笔重现，不复制雕像姿势、经典画作布局或影视人物妆造。
