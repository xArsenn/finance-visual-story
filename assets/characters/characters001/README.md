# characters001：旧版真人角色封存

本目录保存阿森、米露的旧版真人视觉母版，以及迁移前的完整长期角色设定快照。编号 `characters001` 是历史版本编号，不是现行人物模板。

- `asen-character-master.png`：旧版真人阿森。
- `milu-character-master.png`：旧版真人米露。
- `brand-audience-characters-human-legacy.md`：旧版三人角色设定，包括当时的阿杰文字外观。

默认生成必须使用上级目录中的暖橙色小龙阿森与好奇猫咪米露母版。除非用户明确要求调用 `characters001` 复刻或对照，否则不得把本目录的真人形象混入现行漫画。封存文件可恢复，不得静默覆盖。
